# Visual Design System: Vernier

## 1. Aesthetic Direction: Swiss Metrology & High-Density Telemetry
Vernier rejects generic crypto-neon and AI-purple gradients. It draws inspiration from 17th-century Swiss watchmaking calibration, precision laboratory calipers, and aerospace mission telemetry.

### Palette & Tokens
- **Background Deep:** `#0A0D14` (Obsidian slate baseline)
- **Surface Card:** `#0F172A` (Graphite instrument panel)
- **Surface Elevated:** `#1E293B` (Border and elevated control pod)
- **Primary Accent / Needle:** `#F59E0B` (Calibrated warm amber)
- **Telemetry Beam:** `#06B6D4` (Electric cyan active scan beam)
- **Breach / Alert:** `#EF4444` (Pathogenic call alert crimson)
- **Conform / Safe:** `#10B981` (Verified clean state emerald)
- **Muted Label:** `#94A3B8` (Laser-etched secondary notation)

---

## 2. Typography Scale
- **Display Monospace:** JetBrains Mono / Geist Mono for all addresses, opcodes, storage slots, and numeric deltas.
- **Interface Sans:** Inter / Geist Sans for high-legibility headings and body copy.
- **Scale:**
  - Micro: `10px` (Laser-etched scale ticks, opcode indexes)
  - Small: `12px` (Telemetry labels, status indicators)
  - Base: `14px` (Code blocks, parameter tables)
  - Subhead: `18px` (Section titles, intent summaries)
  - Header: `28px` - `36px` (Hero headline)

---

## 3. Mandatory Avoid-List
- ❌ No floating laptop/phone mockups.
- ❌ No generic AI-purple/pink mesh gradients.
- ❌ No sluggish animated loading spinners (sub-400ms immediate state feedback).
- ❌ No multi-row stacked navigation headers.
- ❌ No competing primary action buttons.
